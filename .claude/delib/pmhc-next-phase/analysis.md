# Analysis — What is the smallest pMHC replication that reuses Cognate's evaluation stack to explain the contrast with TCR-peptide prediction, without drifting toward novelty?

## Flow gaps

- The replication has verified calls into the baseline, embedding, and metrics modules, but no verified dataset or target-label input. That makes the proposed flow structurally reusable but not yet executable as a pMHC study. _(node: **pMHC class I presentation replication**; open edge: **pMHC class I presentation replication → pMHC dataset and target labels**)_
- The intended endpoint is unresolved between binding and presentation, so neither the labels nor the interpretation of the reused scores has a stable meaning yet. This must be fixed before model or dataset selection. _(node: **pMHC class I presentation replication**; open edge: **pMHC class I presentation replication → binding or presentation endpoint**)_
- The pMHC split and grouping contract is absent even though the reused metrics include macro groupwise AUC0.1 and bootstrap comparisons. Without a verified grouping unit, the headline comparison could measure a different generalization problem than the TCR evaluation. _(nodes: **pMHC class I presentation replication**, **src/cognate/metrics.py**; open edge: **pMHC class I presentation replication → split and grouping contract**)_
- The literature gate is mentioned as a prerequisite but has no verified source or output, leaving no bounded rule for which replication target is admissible and where replication ends and novelty begins. _(nodes: **pMHC class I presentation replication**, **docs/pmhc/brief.md**; open edge: **pMHC class I presentation replication → literature source or gate artifact**)_
- No reference comparator is connected to the replication. A contrast with TCR-peptide prediction can still be descriptive, but a pMHC replication claim cannot yet be anchored to the field's reference behavior. _(node: **pMHC class I presentation replication**; open edge: **pMHC class I presentation replication → NetMHCpan or another reference comparator**)_
- Reuse is not verified end to end at the test boundary: the map lists focused baseline, embedding, metric, comparison, and frozen-contract tests, but contains no test-to-source call or import edges. _(nodes: **tests/test_baseline_knn.py**, **tests/test_embed.py**, **tests/test_metrics.py**, **tests/test_comparison.py**, **tests/test_frozen_contract_hashes.py**; open edge: **Test modules → source modules**)_

## Rewrite candidates

- Treat `docs/pmhc/brief.md` as the first rewrite target: it is the sole mapped source of the three reuse calls, yet the replication remains only designed. The brief should become a closed replication contract once the endpoint, dataset, comparator, and split decisions are evidenced. _(nodes: **docs/pmhc/brief.md**, **pMHC class I presentation replication**; edges: **pMHC class I presentation replication → src/cognate/baseline_knn.py**, **→ src/cognate/embed.py**, **→ src/cognate/metrics.py**)_
- Treat `src/cognate/baseline_knn.py` as an adapter seam rather than an unquestioned drop-in. Its mapped behavior is per-group nearest-positive retrieval, so reuse is load-bearing on a pMHC definition of group, reference positives, and exact-match controls that the map does not yet supply. _(node: **src/cognate/baseline_knn.py**; edge: **pMHC class I presentation replication → src/cognate/baseline_knn.py**)_
- Audit the public contract of `src/cognate/metrics.py` before changing its internals. It is the only mapped route to AUROC, AUPRC, macro groupwise AUC0.1, diagnostics, intervals, and paired comparisons, which makes it both the strongest reuse seam and the main place an incompatible pMHC grouping choice would propagate. _(node: **src/cognate/metrics.py**; edge: **pMHC class I presentation replication → src/cognate/metrics.py**)_
- Keep the closed TCR contract frozen and define any pMHC contract separately. Extending the existing hash boundary would make a new designed replication share a change-control surface with a built, closed evaluation. _(nodes: **tests/test_frozen_contract_hashes.py**, **docs/final_state.md**, **pMHC class I presentation replication**)_
- Normalize cache selection at the replication boundary before adding pMHC-specific embedding code. The current cache is selected through either `COGNATE_CACHE_DIR` or the repository shared directory, so implicit path choice is a brittle input to an otherwise reusable embedding flow. _(nodes: **Shared embedding cache**, **src/cognate/embed.py**; edge: **src/cognate/embed.py → Shared embedding cache**)_

## Optimization

- Reuse the three mapped modules in place and add only the pMHC-specific data/contract boundary around them; duplicating baseline, embedding, or metric machinery would add a second implementation without a mapped need. _(node: **pMHC class I presentation replication**; edges: **pMHC class I presentation replication → src/cognate/baseline_knn.py**, **→ src/cognate/embed.py**, **→ src/cognate/metrics.py**)_
- Make the shared cache the first reuse checkpoint, because embedding generation, lookup, serialization, and cache consumption already converge there. A new cache design is unnecessary unless the eventual pMHC representation cannot use this verified path. _(nodes: **src/cognate/embed.py**, **Shared embedding cache**; edge: **src/cognate/embed.py → Shared embedding cache**)_
- Keep the evaluation surface to the metrics already mapped in `src/cognate/metrics.py`; adding a new metric family would be novelty unless the literature gate requires it. The existing scikit-learn edge already supplies AUROC, AUPRC, and standardized partial AUC. _(nodes: **src/cognate/metrics.py**, **scikit-learn**; edge: **src/cognate/metrics.py → scikit-learn**)_
- Use the closed TCR evidence artifacts as constraints rather than rebuilding their analysis: `docs/final_state.md` for the settled contract, `docs/belief_list.md` for claim boundaries, `docs/lessons.md` for transfer rules, and `docs/redteam_curve.md` for known inference sensitivities. _(nodes: **docs/final_state.md**, **docs/belief_list.md**, **docs/lessons.md**, **docs/redteam_curve.md**)_
- Frame the contrast around a single matched evaluation question, not an expanded architecture comparison. The mapped TCR evidence is prior-only on unseen peptides, while the pMHC node is only designed; matching endpoint, split, grouping, and metrics is therefore more informative than adding model variants. _(nodes: **TCR–epitope evaluation**, **pMHC class I presentation replication**, **src/cognate/metrics.py**)_
